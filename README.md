# Movie Review Sentiment Analysis 🎬

## Project Overview
This project focuses on classifying movie reviews as Positive or Negative using Natural Language Processing (NLP) and Machine Learning techniques.

## Business Objective
To automatically understand audience opinions about movies by analyzing textual reviews and identifying positive and negative sentiments.

## Dataset
- Dataset: IMDb Movie Reviews
- Total Records: 50,000
- Features: Review and Sentiment
- Target Variable: Sentiment

## Project Workflow
1. Data Collection
2. Exploratory Data Analysis
3. Text Preprocessing
4. Label Encoding
5. Bag of Words (CountVectorizer)
6. Model Training
7. Model Evaluation
8. Sentiment Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- CountVectorizer
- Machine Learning

## Key Learnings
- Text preprocessing
- Feature extraction using Bag of Words
- Sentiment classification
- Machine Learning model development
- Working with unstructured text data
